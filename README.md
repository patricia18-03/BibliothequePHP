# 📚 Système de Gestion de Bibliothèque

Application web de gestion de bibliothèque développée en PHP POO.

## 🚀 Fonctionnalités

- Catalogue de documents (Livres, BD, Magazines)
- Gestion des emprunts et retours
- Réservation de livres
- Recherche dans le catalogue
- Statistiques
- Interface web responsive

## 🛠️ Installation

1. Cloner ou copier dans `C:\laragon\www\bibliotheque\`
2. Démarrer Laragon
3. Accéder à `http://localhost/bibliotheque/`

La base de données est automatiquement créée au premier lancement.

## 📖 Utilisation

- Accueil: Liste de tous les documents
- Filtrer par type (Livres/BD/Magazines)
- Rechercher par titre ou auteur
- Page détail pour emprunter/réserver/retourner
- Page membres pour voir les emprunts
- Page statistiques

## 👨‍💻 Technologies

- PHP 8.3
- SQLite
- HTML5/CSS3
- PDO
